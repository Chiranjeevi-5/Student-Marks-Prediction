# Student Marks Prediction using Linear Regression

## Project Overview
This project predicts student examination scores based on study hours and attendance using Machine Learning.

## Objective
To build a Linear Regression model that estimates student exam scores using study hours and attendance percentage.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
Student Performance Factors Dataset.

Dataset Source: [Kaggle - Student Performance Factors](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors)

## Features Used
- Hours Studied
- Attendance

## Target Variable
- Exam Score

## Project Workflow
1. Importing libraries
2. Loading the dataset
3. Exploratory Data Analysis (EDA)
4. Checking missing values and duplicates
5. Data cleaning
6. Selecting input and target features
7. Train-test splitting
8. Linear Regression model training
9. Model prediction
10. Model evaluation
11. Predicting marks for a new student

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## How to Run

1. Download or clone this repository.
2. Install the required libraries:

   `pip install pandas numpy matplotlib seaborn scikit-learn joblib`

3. Open `Student_Marks_Prediction.ipynb` in Jupyter Notebook.
4. Run all cells.
